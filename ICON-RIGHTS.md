## Exact asset and modifications

Original recorded source: https://storage.googleapis.com/gweb-gemini-cdn/gemini/uploads/c546a20243c57b297546630cf76e417a2483acb8.svg

The original 66-by-66 SVG sparkle path is retained verbatim as the compound-path prefix. The GG++ SVG adds a blue/purple gradient and two plus-shaped transparent cutouts using `fill-rule="evenodd"`. It is genuine vector geometry, not an SVG wrapper around a PNG. `static/icons/userscript.svg` is embedded unchanged as the userscript metadata SVG data URI; the PNG is a separate backup. Exact source/asset hashes are in [the provenance record](sites/gemini/USERSCRIPT-ICON-PROVENANCE.md).
